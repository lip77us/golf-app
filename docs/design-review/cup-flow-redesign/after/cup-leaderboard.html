Cup leaderboard — nav + match rows

Two problems, one screen. The tab strip mixes which competition with which view, so five tabs scroll and clip mid-word. And the line that matters most — four match segments — is set as prose in the smallest type on the page: “1 UP thru 6, AS thru 6, AS thru 6, AS thru 6”.

Navigation

  • Competition is a selector, not a tab. A tournament can carry several cups, and that count is unbounded — a tab strip cannot be.
  • Views are a fixed segmented control of four that fits 390px with no scroll, so the reader always sees every view available.
  • The “One Round Ryder Cup” badge came off every match card. It held the same value on all of them, so it carried no information; it now sits once, under the competition name, next to the points rule.

Match cards

  • Four segment cells replace the comma run. Each names its segment, so you can see that Fourball is won and the singles have not started — the shipped string cannot express that.
  • Colour plus a square marks the leader, and a completed segment is stamped Final — without it, 1 UP reads the same whether the point is banked or still in play. AS is deliberately grey, because all-square is not a result. Segments not yet begun are dashed and name the hole they start on instead of showing a misleading AS.
  • Thru moves to the header — it was repeated four times per card for a single value.
  • The points bar makes the clinch line spatial: 12 points are in play, so the notch sits at 6½ — “how close is this” is a glance, not arithmetic.

Still open

  • Segment cells assume four per group. Formats with 2 or 6 need the grid to reflow, not scroll.
