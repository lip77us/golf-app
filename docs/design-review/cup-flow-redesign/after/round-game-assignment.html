Games by group

Priced in the wizard, seated here. Round setup already builds the foursomes; this is the step that says which game each foursome plays, once the people are real.

Two shapes of match, and the difference decides the whole screen:

Inside a foursome

  • Nassau pairs, Chapman, Fourball, Singles — the group is two blue and two red (or one and one), so the match is contained. Assigning the game is the whole job.

Between two foursomes

  • Irish Rumble and a four-man scramble put one ball per side, so the foursome is all blue or all red and needs an opposite number. The screen pairs them and shows the match as two stacked sides.
  • Red against blue, always. A blue foursome with no red opponent is not a match, so it is drawn as an incomplete one — named, with the fix offered — and Start Round stays disabled until every game balances.

Reading the screen

  • Grouped by game, not by group number. A captain checks the day one game at a time — “is the Rumble even?” — and the count sits in each game’s header.
  • Points come along for the ride: each game header carries the value set in the wizard, and the tally at the bottom is the first honest points in play for the round, because only now do the matches exist.
  • An odd twosome is not an error. It takes Singles and pays its point like anything else.

Still open

  • Whether the app should propose an assignment — pair the Rumble foursomes by tee time, drop leftovers into Singles — and let the captain correct it, rather than starting empty.
  • Mixed sizes: a two-man scramble is a foursome carrying two matches, not one. Drawn here as one row per match, but the tee sheet still says four golfers.
