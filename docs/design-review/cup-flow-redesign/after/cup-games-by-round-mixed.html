Games & points by round

The step asks a round to choose one format. A cup that is not a Triple Cup does not work that way: a day is a set of games running side by side, and each foursome plays exactly one of them.

Two questions, in this order. Which games does this day run — then how much of the field plays each, and what is each worth. By this step the sides are sized, so the field is a known quantity and the arithmetic is real.

Every game counts in its own unit

Asking for “how many matches” would make the captain do the division. Each game is counted in the thing it is actually built from:

Counted in foursomesFourball, Nassau pairs, Two-man Chapman, Chapman Nassau, Foursomes, Foursomes Nassau. Two per side inside the group — one match each.
Counted in twosomesSingles, Singles Nassau. One per side — one match each.
One match at mostIrish Rumble, Scramble. On or off. The whole group is one side, so the match is a blue foursome against a red one: 4 per side, 8 golfers, and there is no second one to count.

The count is the pick

  • There is no checkbox. A game is in the day when its count is above zero, so picking and sizing are one gesture instead of two screens.
  • Each row states what one costs per side — a Nassau foursome is 2 per side, a Singles twosome 1, a Rumble match 4.

The field meter

  • The meter counts against one side, not the whole field. Every match is red against blue and takes the same number from each, so the honest target is the roster size — 16 here — and one number covers both sides.
  • Golfers not yet committed are named as a number, not an error — a captain may deliberately leave a pair for the last game they add.
  • Nothing is greyed on arithmetic alone. Overcommitting is shown as a number over the target, so the captain fixes the count they meant to change rather than the one the app chose.

Points

  • The foursome-against-foursome games are a toggle, not a count: one match or none, capped at 8 golfers.
  • Priced on the round card, next to the count — the stepper on the right of each row sets what one match of that game is worth, and the round total beside it updates. Per game, per day: Irish Rumble can be worth 2 on Saturday and 1 on Sunday.
  • Multi-segment games show the multiplication: Nassau pays front, back and overall, so 1 pt × 3 is 3 a match.
  • Because both the count and the price are set here, the round total is real — and so is the cup total and the number it takes to win.

Carried forward

  • Every match is red against blue, enforced when the foursomes are seated on Games by group. This step sets how many of each; that step says who.
  • Triple Cup stays exclusive — it spends all 18 holes, so it replaces the list.

Every team game comes in two

A game that pays one result and the same game paying front, back and overall are different games to a captain: they cost different points and change how a day is priced. So each is its own row rather than a segment switch hidden inside one.

Fourball
Nassau pairs		Best ball of the pair — one match, or three segments.
Two-man Chapman
Chapman Nassau		Both drive, swap, then one ball — one match, or three segments.
Foursomes
Foursomes Nassau		Alternate shot — one match, or three segments.

All six count the same way, 2 per side per foursome, and a Nassau variant takes its base game’s handicap allowance. Foursomes is what a real multi-day Ryder Cup runs alongside fourball; a mixed cup that cannot offer it cannot run one.

Naming: the list reads cleaner as Fourball / Fourball Nassau to match the other two pairs, but Nassau pairs is the name already in the app. Worth settling before the strings are written.

Settled

  • A halved match splits the point — ½ to each side, always, in every game. Not a per-game setting.
  • One cup-wide handicap allowance, set once in the wizard, applies to every game in every round.
  • The point unit is free per round. Irish Rumble can pay per match on Saturday and Nassau per segment on Sunday; the stepper on each round card is the only place it is set.
  • An odd twosome gets a Phantom partner, as the Triple Cup does — offered automatically once the counts leave a golfer over.
