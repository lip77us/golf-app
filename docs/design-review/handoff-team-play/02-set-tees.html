Set tees

Every golfer needs a tee before handicaps can be computed, so this step is a confirmation, not a blank form: tees are pre-suggested by sex and the screen is already valid on arrival. The work is overriding the ones that don’t fit.

Two levels of set

  • Set all on the group header assigns every golfer in that group at once — the common case, since most groups play one tee.
  • Per-golfer picker for the exceptions. The group header keeps its own control so “set all, then fix one” is two taps.

The menu earns its height

  • Each option carries yards · rating/slope · par — the numbers that actually change the handicap. Colour alone can’t answer “which tee should I play?”
  • The same tee rates differently by sex, and sometimes measures differently too. The menu shows the rating set for the golfer it was opened from — the header names which one (“women’s rating”) so a shared number is never mistaken for a shared card. A tee with no rating for that sex should be hidden, not listed unplayable.
  • The current selection is held, not just ticked, so re-opening reads as a state rather than a fresh choice.
  • Tees are listed as the course publishes them, including duplicates like White and White – sixes. Do not sort or de-duplicate: a named variant usually means a different card.

Rules

  • An unset golfer shows a loud Pick tee chip and blocks Configure Round. Nothing else on the screen is destructive, so there is no confirm.
  • Groups are by sex only because that is what the suggestion keys off. A group with no golfers is not rendered.
  • The pill shows colour · yardage — enough to spot a wrong tee at a glance, with the full detail one tap away.
