Score entry, tournament

The hole card a tournament foursome actually uses. Everything the live build gets right is kept — hole header, CH chip, stroke dots, the ball badge on the carrier, the bracket summary that updates hole to hole. Three things change.

Spots ride along

The casual Stroke Play + Spots screen already has the answer: a − / + stepper per golfer, per hole. Nothing to invent — the same control appears here, because a spot is a fact about a hole that no score implies and nothing downstream can reconstruct.

A spot is a count, not a type. No greenie, sandie or poley picker — especially not in a tournament, where the hole card is already carrying four golfers, a ball game and a bracket. If the group wants to know what the spot was for, they know; the app does not need to.

The stepper only exists if this group chose spots. No spots game, no control — not a disabled one, not a placeholder. A group that did choose it and has a golfer sitting out shows Not in spots on that row, so the card never offers a control that records something a man cannot win.

In practice this is the rare case. A foursome already carrying the ball game, Irish Rumble and a bracket is unlikely to add a side game on top — so the default state of this card is the one with no steppers at all, and spots is the exception it has to accommodate rather than the shape it is built around.

Who sets itThe foursome, in its own game setup, exactly as casual. The TD never sees it.
Where it landsThis card, on the hole it happened. The only foursome side bet that needs entry.
Who sees itOnly this group. Other foursomes carry their own games, or none.
Everything elseRabbit, survivor, skins, Nassau read the tournament’s scores and are followed on the leaderboard — no second card.

One control for the lost ball

Live draws a radio circle and a switch for one act. One switch, and it says what it does: this ends the game for the group, so the label carries the consequence rather than describing a checkbox.

The pager says why

Live greys Hole 2 with no reason. Here the button stays live and the line underneath names what is missing — and it disappears the moment the fourth score lands.

What is inherited

Stroke dots and the gets N chip are the casual convention, carried through. The bracket summary uses short names and the vs. TBD label decided this week.
