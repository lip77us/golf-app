How the match works
A single 18-hole match. Each hole goes to the lower score (per the handicap mode above); tied holes are halved. Whoever is up after 18 holes wins the match.
—No Advanced panel here: a single match has no nines to press, no 2nd-ball / Claremont variants, and a fixed ceiling — so presses, game variant and the loss cap are all hidden. Only the full three-match Nassau shows them.
