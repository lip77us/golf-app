Sixes — segment draw

A slot-reel that draws a 2v2 pairing. Splitting four players into two teams has exactly three possible pairings — the top row paired with row 2, 3, or 4 — and which one gets played is genuinely random, the call groups used to settle by flipping a ball marker on the tee.

Three places it’s used

DrawHow it opensChoices
Segment 1Setup screen — “Randomly assign teams” button under the drag rows3 pairings
Segment 2Auto — opens once Segment 1 is settled (an early close-out can fire it on hole 4/5)2 pairings
Extra matchEnd-of-round team picker — same “Randomly assign teams” button3 pairings

Drag or spin. Segments 1 and the extra match reach this screen from a button that sits beside the drag-to-sort rows — the group can still drag the teams by hand, or spin (and re-spin). Segment 2 is the one forced draw. Segment 3 is never drawn: once Segment 2 lands the last pairing is fixed, and Match 3 is simply announced on the segment strip.

Concealed until spun

  • The reel window shows only “Spin to select next partners” while idle — the candidate pairings are not listed beforehand. The reveal is the point.
  • On landing, the candidate rows drop in: the winner rings pine and takes the segment mark, the loser dims to 32%.
  • Player names are capped to first names (with ellipsis / shrink-to-fit) so a two-player pairing never overflows the reel or the rows.

One reel, not three

  • The reel carries whole pairings — Side A / Side B alternating. Picking one side determines the other, so three independent reels would misrepresent the draw.

Motion spec

  • 2.55s, cubic-bezier(.12,.62,.15,1) — fast out, long decelerating tail, no bounce-back past the winner. 1.7px blur lifts partway so the last rows read as they pass.
  • Window flashes mint and the housing takes a 3px thunk on landing. Bulbs pulse only while spinning.
  • The winner is picked before the animation starts — the reel is a reveal, never the randomness. Tap the machine to skip; reduce-motion lands instantly.

Front-end reveal. The draw is computed on the device (no server round-trip); a per-device flag remembers that the auto Segment-2 draw has already been shown so re-entering the round doesn’t replay it. The setup / extra-match draws are re-openable so the group can re-spin.
