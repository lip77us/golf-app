Leaderboard — Triple Nassau

Three players, three simultaneous one-on-one Nassaus. The matrix reads the whole game at a glance — one row per match, one column per bet. A solid cell is settled; a tinted one is still live and shows holes played, so a Front 9 that ended 2 UP never reads the same as a Back 9 sitting 2 UP with holes to go. Below it: the presses across all three matches, the round-progress gross card (SI + per-match allowances + hole winners), and the net position (each player's two matches netted). Player identity is colour throughout, never “P1/P2”.
