One card per group. Header line = Survivor — {handicap} · {n} decided with a status pill. Per-player rows show Survivors won and money. The breakdown lists each Survivor’s range and how it ended — won, split (final two tied on the last hole), no blood, or still in play. Below it the shared scorecard grid (the same widget Sixes / Wolf / Rabbit use) shows gross per player per hole with stroke dots; the hole’s winner is tinted green and the player knocked out on it red. The red tint is a Survivor-only flag on the shared grid — every other game omits it and is unchanged. Entry stays on the play screen; this is summary only.
